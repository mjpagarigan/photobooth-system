# Lock each session to an explicitly active frame

Frames retain their uploaded dimensions and may contain 1–10 independently positioned slots. The operator explicitly marks one visible frame as active for new sessions; session start locks that frame and its shot count so later editor changes cannot alter an in-progress capture. Review may choose another visible frame only when it has the locked shot count. Archiving the active frame selects the next visible library item, falling back to the previous item, while the final visible frame is protected.
